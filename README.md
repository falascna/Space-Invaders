# Space-Invaders
Simple Space Invaders game written in Verilog. This was made for the final project for ECE 287 at Miami University.
To start the game flip SW[0] to 1. Use KEY[2], KEY[1], and KEY[0] to move left, shoot, and move right respectively. Once you win or lose, flip SW[0] to 0 and then back to 1 to reset the game.

*Note: The folder "db" was too large to upload, so I split it into two folders. If downloading the code, simply copy the contents of "db2" into "db" and then delete "db2."*
